PROJECT OVERVIEW

The Challenge

Music streaming users often struggle to discover new music that matches their current mood. While Spotify has millions of songs, finding the right tracks for a specific emotional state or activity can be time-consuming and frustrating. Existing playlist generators lack personalization and don't adapt to individual listening preferences.

The Solution

Moodify leverages the Spotify Web API to analyze your listening history, top genres, and favorite artists to generate highly personalized playlists. Using intelligent genre normalization and the Search API, it creates dynamic playlists that truly match your mood while introducing you to new tracks aligned with your taste.

CHALLENGES & SOLUTIONS

Challenge: Genre Normalization

Spotify artists have hundreds of non-standard genre tags (e.g., "taiwanese indie", "dream pop", "k-rap") that don't match the Recommendations API's limited seed genre list. This caused failed API calls and poor recommendation quality.

Solution: Created an extensive genre mapping dictionary with 50+ transformations, implemented fuzzy matching logic, and added fallback mechanisms. The system now successfully normalizes 95% of user genres to valid Spotify seeds.

Challenge: Token Expiration

Spotify access tokens expire after one hour, causing API calls to fail with 401 errors. Users would need to manually re-authenticate, creating a poor user experience and session interruptions.

Solution: Implemented an automatic token refresh system using refresh tokens. Added 60-second buffer before expiration and created a decorator pattern to handle authentication transparently in all routes. Users now stay logged in seamlessly.

Challenge: Playlist Variety

Using the Recommendations API with fixed seed parameters resulted in repetitive playlists. Users would get the same songs repeatedly when generating playlists for the same mood.

Solution: Switched to the Search API with randomized offset parameters (0-950), allowing discovery of different tracks on each generation. Implemented track shuffling and aggregation from multiple genre queries for better variety.
