Overview

Project Overview

The Challenge

Music streaming users often struggle to discover new music that matches their current mood. While Spotify has millions of songs, finding the right tracks for a specific emotional state can be time-consuming and frustrating.

The Solution

Moodify leverages the Spotify Web API to analyze your listening history, top genres, and favorite artists to generate highly personalized playlists that truly match your mood while introducing you to new tracks aligned with your taste.

Challenges

Challenges & Solutions

Genre Normalization

Spotify artists have hundreds of non-standard genre tags that don't match the Recommendations API's limited seed genre list, causing failed API calls and poor recommendation quality.

Solution: Created an extensive genre mapping dictionary with 50+ transformations, implemented fuzzy matching logic, and added fallback mechanisms.

Token Expiration

Spotify access tokens expire after one hour, causing API calls to fail with 401 errors and requiring manual re-authentication.

Solution: Implemented an automatic token refresh system using refresh tokens with a 60-second buffer before expiration.

Playlist Variety

Using the Recommendations API with fixed seed parameters resulted in repetitive playlists with the same songs appearing repeatedly.

Solution: Switched to the Search API with randomized offset parameters (0-950), allowing discovery of different tracks on each generation.
