Overview

Project Overview

The Challenge

Spotify holds millions of songs, but finding tracks that fit a specific mood means digging through them by hand.

The Solution

Moodify reads listening history, top genres and artists through the Spotify Web API, then generates a mood playlist weighted to that taste.

Features

Key Features

Spotify OAuth

Spotify OAuth 2.0 with automatic token refresh — no manual re-login.

Personalized Analysis

Reads top tracks, favourite artists and listening patterns to model taste.

Smart Genre Matching

Maps 50+ non-standard genre tags onto Spotify's recommendation seeds.

Dynamic Playlists

Mood playlists built on the Search API with randomised offsets for variety.

Mood Selection

Five moods — Chill, Energetic, Focus, Sad, Happy — behind a visual selector.

Auto Token Refresh

Challenges

Challenges & Solutions

Genre Normalization

Artists carry hundreds of non-standard genre tags that don't match the Recommendations API's limited seed list — failed calls and weak recommendations.

Solution: A 50+ entry genre mapping dictionary, fuzzy matching, and fallbacks.

Token Expiration

Access tokens expire after an hour, so calls fail with 401 and users have to log in again.

Solution: Automatic refresh on a 60-second buffer before expiry.

Playlist Variety

Fixed seed parameters on the Recommendations API returned the same songs every time.

Solution: Switched to the Search API with randomised offsets (0–950).
