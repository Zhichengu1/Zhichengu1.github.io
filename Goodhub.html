Overview

Project Overview

The Challenge

Many environmentally conscious individuals struggle to find and engage with local volunteer opportunities. Existing platforms lack intuitive interfaces and real-time updates, making it difficult for users to discover events that align with their interests and availability.

The Solution

GoodHub provides an interactive map-based interface that allows users to easily discover, join, and create sustainability-focused events. The platform features real-time updates, user profiles, event management, and social features to build a community of environmental advocates.

Features

Key Features

Interactive Map

Leaflet-powered map interface displaying volunteer opportunities with real-time location tracking and filtering capabilities.

Event Creation

Users can create and manage their own environmental events with custom descriptions, dates, and locations.

Community Hub

Connect with like-minded individuals, join groups, and build a network of environmental advocates.

User Profiles

Customizable profiles tracking volunteer hours, events attended, and environmental impact contributions.

Smart Filters

Advanced filtering options by event type, date, distance, and impact category for personalized discovery.

Responsive Design

Fully responsive interface optimized for desktop, tablet, and mobile devices with seamless user experience.

Process

Development Process

Phase 1: Planning & Design

Hours 0-8

Conducted user research, created wireframes, defined core features, and established the technical architecture. Designed the database schema and API endpoints for seamless frontend-backend integration.

Phase 2: Core Development

Hours 8-32

Built the React frontend with component architecture, integrated Leaflet API for map functionality, developed Flask backend with RESTful APIs, and implemented user authentication and database operations.

Phase 3: Feature Enhancement

Hours 32-44

Added advanced filtering, real-time updates, user profiles, event management dashboard, and social features. Optimized performance and implemented responsive design across all device sizes.

Phase 4: Testing & Deployment

Hours 44-48

Conducted comprehensive testing, fixed bugs, optimized performance, prepared presentation materials, and deployed the application for the hackathon demo.
